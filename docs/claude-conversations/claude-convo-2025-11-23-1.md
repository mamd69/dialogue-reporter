# Claude Code Overview

**Claude Code is Anthropic's official CLI** that brings Claude AI directly into your terminal and development workflow as an AI pair programmer.

## What Makes It Special

Unlike regular Claude (web/API), Claude Code is purpose-built for development with:

- **Direct File System Access** - Read, write, and edit your codebase
- **Terminal Integration** - Execute commands, run tests, interact with build systems  
- **Project Context** - Automatically understands your entire codebase structure
- **IDE Integration** - Works natively in VS Code, JetBrains, and terminals

## Key Capabilities

**Core Development:**
- Understand complex codebases quickly
- Debug and fix bugs with context awareness
- Refactor code safely with best practices
- Generate new code and boilerplate
- Create comprehensive test suites

**Advanced Features:**
- **Extended Thinking** - Deep reasoning about complex problems
- **Plan Mode** - See Claude's strategy before implementation
- **Custom Slash Commands** - Create project-specific automation
- **Hooks System** - Automate pre/post task operations
- **MCP Servers** - Extend with specialized tools

## Main Use Cases

- Pair programming & faster development
- AI-powered code reviews
- Learning unfamiliar codebases
- Automated documentation
- Test-driven development
- System architecture design
